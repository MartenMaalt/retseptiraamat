# Cookbook

Reageeriva kujundusega retseptiraamatu maandumisleht Tartu Ülikooli aine „Veebilehtede loomine edasijõudnutele” teise ülesande jaoks.

## Funktsioonid

- semantiline HTML;
- arvuti- ja mobiilivaade;
- sujuv navigatsioon lehe osade vahel;
- klaviatuuriga kasutatav retseptikaartide fookus;
- CSS-animatsioon, mis näitab arvutis köögi nime pildi kohal hõljutades;
- mobiilis alati nähtavad köökide nimed;
- kohalikud ja optimeeritud pildifailid.

Piltide päritolu ja kasutustingimused on failis `sources.md`.
